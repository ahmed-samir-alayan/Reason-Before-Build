# Nocturne visual style

This is the selected artwork direction for this repository. It draws its palette and painted atmosphere from the author's supplied blue profile image.

## Palette and material

Midnight navy `#05141F`, deep blue `#083451`, ocean blue `#225F8B`, slate `#536B95`, and soft blue `#6B86A9` provide the main field. Lavender, ivory, and a restrained peach highlight distinguish the diagram and resolved action. The values in [style-tokens.json](assets/style-tokens.json) are palette references rather than a claim that every painted pixel uses an exact token.

Fine luminous paths carry the skill's central idea: many possibilities become one deliberate change after reasoning. Keep quiet space around the title and labels. The author's name appears once in the artwork, and the category reads **A SKILL**.

## Lettering

The title uses custom generated high-contrast editorial serif lettering. Supporting labels use generated monospaced lettering. These are rendered into the image, not provided as a named font family or editable live text. See [artwork notes](assets/TYPE-NOTICES.md).

The GitHub README body retains GitHub's normal typography. A generic artwork label does not establish compatibility with agent hosts beyond those described in the installation guide.

## Files and reproduction

- `docs/assets/cover.png`: original 1774 × 887 cover, used in the README.
- `docs/assets/social-preview.jpg`: 1280 × 640 export under 1 MB, for GitHub's social-preview upload.
- [artwork-prompt.md](assets/artwork-prompt.md): the exact prompt used with the built-in imagegen tool.

The profile image was a palette and mood reference and is not bundled in the public package. Reproduction requires an appropriate reference image and a generation tool; the same prompt does not guarantee an identical result.

Future skill covers can reuse the palette and material treatment while giving each capability a relevant illustration. Adoption across other repositories remains a separate design choice.
