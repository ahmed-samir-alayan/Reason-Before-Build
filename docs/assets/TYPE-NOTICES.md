# Artwork and lettering notes

The selected Nocturne cover was created with the built-in imagegen tool from a written design brief and the author's supplied profile image as a palette and mood reference.

The artwork contains custom generated editorial serif and monospaced lettering. It does not use or distribute a named font binary. The lettering is part of the bitmap and cannot be edited as live text. Earlier vector-based design candidates are not part of this public package.

The exact [generation prompt](artwork-prompt.md) is included for design continuity. The project license is in [LICENSE](../../LICENSE). The README's body text follows GitHub's own typography.
